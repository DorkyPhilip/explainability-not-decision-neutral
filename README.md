# Explainability Is Not Decision-Neutral in Clinical Language Models

Code and data to reproduce every result in the accompanying article.

**No patient-level data from MC-MED or MIMIC-IV-ED is redistributed here.** See
[What is not in this repository](#what-is-not-in-this-repository).

Three open-weight language models were asked to recommend an emergency
department disposition (admit or discharge) for the same 2000 mid-acuity
encounters under 19 different elicitation conditions. The conditions differ only
in the instruction appended to an otherwise identical prompt: whether the model
must produce a justification, whether that justification is recorded, and which
harm the justification is required to name. The patient information is byte-identical
across conditions. An additional ablation repeats five of these conditions, the
recorded-note and risk-valence prompts, with the phrase "subject to
quality-assurance audit and medico-legal review" removed.

The headline result is that requiring a model to document the risks of
discharging versus the risks of admitting moves the admission rate for identical
patients by roughly 15 percentage points, and that the default explainability
instruction ("document your reasoning and the risks") behaves like the
discharge-risk framing rather than like a neutral one.

## Reproducing the reported statistics

No credentialed data access, API key, or GPU is needed. The decision-level
dataset released with the article contains every model decision behind every
reported number.

```bash
pip install -r requirements.txt
python -m elicitation.analysis   # Table 1, marginal rates, S7 and S8 Tables, replication
python -m elicitation.figures    # writes figures/fig1.png ... fig5.png (--tiff DIR for TIFFs)
```

Two results need one extra step because they compare against the treating
clinician's disposition, which is withheld; see
[What is not in this repository](#what-is-not-in-this-repository).

`elicitation/analysis.py` is the single source of truth for the article: the
manuscript numbers are computed from `data/decisions.csv.gz`, the same file
released as Supporting Information, so the published values and the values a
reader obtains cannot diverge. Bootstrap resampling uses a fixed seed
(`BOOTSTRAP_SEED = 5`) and a deterministic pair ordering, so intervals reproduce
exactly rather than approximately.

## What is in `data/decisions.csv.gz`

One row per model decision (205,938 rows).

| Column | Meaning |
| --- | --- |
| `dataset` | `mcmed` (primary) or `mimic-iv-ed` (external replication) |
| `encounter_id` | Study encounter identifier, `<dataset>-<index>` |
| `model` | `gemma-4-31b`, `nemotron-120b`, or `deepseek-v4-flash` |
| `condition` | Elicitation condition; see `data/prompts.json` |
| `disposition` | `ADMIT` or `DISCHARGE` |
| `confidence` | `LOW`, `MED`, `HIGH`, or empty where not elicited |
| `run` | `1` primary run, `2` independent duplicate run, `3` audit-wording ablation (October 2026) |

`encounter_id` is the encounter's position in the seeded cohort file.
`data/cohort_manifest.csv` maps each one to the source encounter identifier (the
MC-MED visit `CSN` or the MIMIC-IV-ED `stay_id`), so a credentialed user can
locate the study encounters in their own copy of each dataset. The manifest holds
identifiers only: no clinical field, no disposition, and no model output.

Run 3 includes its own Unmonitored arm. Compare each run 3 condition with the
run 3 Unmonitored arm, not with run 1, so that any drift in the hosted models
between June and October 2026 cancels.

`data/prompts.json` contains the verbatim system prompt for all 24 conditions.
It is generated by `python -m elicitation.prompts` from the same module the
runner imports, so the published prompts cannot drift from the executed ones.

## What is not in this repository

Nothing that describes or reconstructs a patient. Specifically, the triage
summaries sent to the models, the cohort files, and the models' free-text
rationales (which paraphrase the patient) are all absent, and the cohort files
and raw run logs are excluded by `.gitignore` so they cannot be committed by
accident. The only source-dataset content is the list of encounter identifiers
in `data/cohort_manifest.csv`, which is meaningful only to someone who already
holds credentialed access to the source datasets.

The treating clinician's actual disposition is also withheld. It is derived from
the source datasets, so redistributing it would amount to redistributing a
column of them. Everything in the article reproduces without it except the two
results that use it as a comparator: the operating-point statistics
(sensitivity, specificity, balanced accuracy) and Fig 3.

Credentialed users can restore it. The manifest identifies each study encounter
in the source dataset directly. Alternatively, because the cohort builders are
deterministic and the study identifier is the encounter's position in the cohort
file, re-running a builder recovers the label by position:

```bash
python -m cohort.build_mcmed_cohort --db mcmed.duckdb --out mcmed_cohort.jsonl
python -m cohort.export_labels --mcmed mcmed_cohort.jsonl
```

That writes `data/clinician_labels.csv`, which `analysis.py` and `figures.py`
pick up automatically; the operating-point section and Fig 3 then run. The file
is listed in `.gitignore` and must not be committed.

## Rebuilding from the source data

This requires credentialed PhysioNet access and an inference API key. See
[docs/REPRODUCING.md](docs/REPRODUCING.md) for the full pipeline, and
[docs/DATA_ACCESS.md](docs/DATA_ACCESS.md) for how to obtain the source datasets.

```bash
python -m cohort.build_mcmed_cohort --db mcmed.duckdb --out mcmed_cohort.jsonl
python -m elicitation.runner --cohort mcmed_cohort.jsonl --out decisions_raw.jsonl \
    --conditions routine mech_discard mech_record mech_risk \
                 valence_admit valence_discharge valence_both
```

Inference is run at temperature 0, but batched GPU inference is not
bit-deterministic even at temperature 0. Rather than claim per-decision
determinism, the article reports an empirical noise floor from an independent
duplicate run of three conditions: per-decision agreement between runs was 88 to
98 percent depending on the model, while condition-level admission rates moved
by at most 1.1 percentage points. Every effect reported in the article is
several times larger than that floor. `python -m elicitation.analysis` prints
the noise floor alongside the effects.

## Repository layout

```
cohort/
  capsule.py              Shared triage renderer (identical surface across datasets)
  build_mcmed_cohort.py   Primary cohort, seeded and deterministic
  build_mimic_cohort.py   External replication cohort, harmonized to MC-MED
  export_labels.py        Restores the withheld clinician label (credentialed only)
elicitation/
  prompts.py              Verbatim prompt definitions for all 24 conditions
  runner.py               Inference runner (resumable)
  analysis.py             All reported statistics
  figures.py              All manuscript figures
data/
  decisions.csv.gz        Decision-level dataset (Supporting Information S1 Data)
  cohort_manifest.csv     Study identifier -> source encounter identifier
  prompts.json            Verbatim prompts, generated from elicitation/prompts.py
figures/
  fig1.png ... fig5.png   Manuscript figures, regenerated by elicitation/figures.py
```

## Ethics

Both source datasets are de-identified and publicly available to credentialed
researchers under PhysioNet data use agreements. The study involved no
prospective patient contact, no intervention, and no protected health
information; model recommendations were never returned to any clinician and
never influenced any patient's care.
